## 结论先行

**检查与修正**是图1七层的最后一层：对中间 / 最终结果做自检，发现偏差则**回退到规划（或其他上游层）再试**。它与图2的 **Reflection** 同族，强调「反馈迭代」这一 Agent 四特征之一。

没有检查与修正，系统只是流水线；有了它，才是可收敛的闭环。

---

## 是什么

图1标注：

- 自我检查、错误检测  
- 从本层回到「规划」的粗箭头：**发现问题并回溯**  

典型流程：

```
执行结果 → 检查（达标？合规？）
         ├─ 是 → 最终答案 / 行动结果
         └─ 否 → 修正策略 → 回到规划或核心循环
```

修正可以是：改参数重试、换工具、改计划、请求人工。

## 应用场景

- 自动质检报告完整性  
- 工具返回空 / 错时的自动换路  
- 与门禁结合：确定性规则失败则**强制**修正或中止（非仅提示）

## 效益

| 效益 | 说明 |
